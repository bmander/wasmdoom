DOOM / BROWSER EDITION

Source & credits.

The original DOOM engine by id Software, made portable by DoomGeneric and its contributors. Based on the work of id Software, Chocolate Doom, and fbDOOM. The engine is compiled from C to WebAssembly with Emscripten.

Download the corresponding source and build scripts · GPL license

DoomGeneric base revision: dcb7a8dbc7a16ce3dda29382ac9aae9d77d21284, with local changes for native rendering up to 1280 × 800 and the optional Worthy Adversaries enemy mod, using the frozen second-hour v4 recurrent neural policy with per-monster memory trained in the offline laboratory. The browser adapter, engine changes, and page are GPL-2.0-or-later and included in the source download.

Game data

The bundled episode is the original DOOM shareware IWAD from the SDL DOOM project. Game graphics, levels, and sounds remain copyrighted by id Software and are separate from the open-source engine. Registered episodes are not included. You can use a locally owned DOOM or DOOM II IWAD.

Libraries

Sound effects use SDL2 and SDL2_mixer (zlib licenses). Compiled with Emscripten (MIT / University of Illinois/NCSA). MIDI music is disabled in this build.
